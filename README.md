# Mobile app user-behavior Analysis

## Project Overview

This project analyzes mobile application user behavior data to identify engagement patterns, usage trends, and user activity levels.

## Tools Used

- Python
- SQL
- Power BI
- Excel

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. SQL Analysis
4. Dashboard Creation
5. Business Insights

## Key Insights

- High app usage increases screen-on time
- Younger users show higher engagement
- Session count impacts usage behavior
- Battery drain increases with prolonged usage
